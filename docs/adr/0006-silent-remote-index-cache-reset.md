# 静默透传与互斥受控的远程索引缓存重置机制

在代码库索引构建失败或缓存失效场景下，需要清理远程代码库索引缓存以支持重建。针对该功能的集成方式，我们做出以下架构决策：

1. **静默透传触发而非二次弹窗确认**：底层 Copilot 命令 `github.copilot.deleteExternalIngestWorkspaceIndex` 已内置全局 Window 进度提示（`Deleting external ingest index...`）及完成通知。作为中继层，本扩展不增设阻断性的确认弹窗，保持操作链条的轻量与迅速。
2. **严格单飞互斥与防重入锁定**：通过 `isResetting` 标志防止用户因连续快速点击而发起并发重复删除，同时与 `indexing`（构建中）状态互斥——若正在构建索引则拦截重置并提醒用户，确保远端操作状态单调一致。
3. **坚持极简双状态模型（遵循 ADR-0004）**：重置缓存执行期间，状态栏不引入第三种过渡状态或额外动画，由底层原生 Window 进度指示承担反馈，执行完成后确保复位为 `idle`。
4. **对称的候选回退与可观测性**：使用 `DELETE_INDEX_CACHE_COMMAND_CANDIDATES` 候选列表隔离底层 Copilot 命令细节，命令缺失时提供精准的本地化警告并记录审计日志。
