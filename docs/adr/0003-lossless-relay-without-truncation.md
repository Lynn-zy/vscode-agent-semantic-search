# 中继层无损透传，不实施人工字符数截断与纯文本强转

早期实现曾设置了 60,000 字符的人工截断上限，以防超大文本填满模型上下文。我们决定彻底移除该限制，由中继层对底层 Copilot 返回的代码片段进行 100% 无损原样透传。因为底层 Copilot 已在 AST 根部内置了 `<TokenLimit max={28000} />` 组件严格管控 Token 预算；作为中继层，不应越界猜测下游各异模型的上下文容量，否则会人为破坏函数或文件的语义完整性。

同时，在工具调用结果输出时，当底层检索命中（`status === "ok"`），直接透传底层返回的原生 `LanguageModelPromptTsxPart` 多态部件，而不是强行展平包装为单一超大 `LanguageModelTextPart`。这不仅完整继承了底层 PromptTsx 的预算控制，更彻底避免了触发 Copilot Chat 对大于 8KB 纯文本结果自动写入 `content.txt` 临时文件的保护机制，实现与官方原生工具完全一致的直接文本输出体验。
